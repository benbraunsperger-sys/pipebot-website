# PipeBot Website

Eigenständige Produkt-Website für PipeBot, den KI-Chatbot von Pipeline AI Solutions.

## Lokal starten

```bash
npm install
npm run dev
```

## Produktion

```bash
npm run build
```

Der statische Export liegt anschließend in `out/` und ist für Netlify vorbereitet.

## Vor Veröffentlichung ausfüllen

- Anschrift im Impressum
- Firmenbuchnummer
- USt-ID
- Datenschutzangaben prüfen, sobald Hosting und optionale Analyse-Dienste final feststehen
